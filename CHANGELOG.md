# Changelog

## 1.1.0 — Nexora Link Control Center

- Added a complete static dashboard at the project root to resolve deployments that previously had no `index.html`.
- Preserved the original Vercel API bridge routes and their OAuth/PKCE/ticket/Telegram proxy behavior.
- Added responsive dashboard navigation, status overview, provider catalog, and API endpoint quick access.
- Added Theme Studio: Dark/Light/AMOLED, color pickers, presets, radius, glass blur, font scale, mobile navigation, branding, localStorage, JSON export/import, and reset.
- Added local endpoint settings, API key validation, Telegram Bot API `getMe` test, optional Nexora Cloud Backend and webhook test, timeout/upload reference values, and browser activity logs.
- Added beginner deployment and Android connection guide.
- Added an Android feature reference document clarifying which features live in the Android app versus Nexora Link or the separate PostgreSQL backend.
- Added deployment/static-root tests; all original bridge tests are retained.
