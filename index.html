ZERO TO DEPLOY

Panduan pemula

Ikuti urutan dari ekstrak ZIP, upload ke GitHub, deploy Vercel, hingga menyambungkan aplikasi Android Nexora Cloud.

LEVEL: PEMULA
ISI PANDUAN01 · Upload ke GitHub02 · Deploy di Vercel03 · Environment Variables04 · Google Drive & Photos05 · GitHub OAuth06 · Telegram Bot07 · Sambungkan Android08 · Atasi error 404
01
SOURCE CODE

Upload proyek ke GitHub lewat HP

  1. Unduh ZIP hasil proyek Nexora Link, lalu ekstrak memakai Files, ZArchiver, atau aplikasi pengelola arsip.
  2. Buka GitHub melalui browser dan masuk ke akun Anda.
  3. Buat repository baru, misalnya nexora-link. Pilih Public atau Private sesuai kebutuhan.
  4. Buka repository → Add file → Upload files. Pilih semua isi folder hasil ekstrak: index.html, vercel.json, folder api, lib, dan aset lainnya.
  5. Pastikan index.html dan vercel.json terlihat di root repository, bukan tertanam di dalam folder ZIP bertingkat. Tekan Commit changes.
ⓘ
Upload isi folder proyek, bukan file ZIP-nya saja. Struktur root yang benar adalah index.html, vercel.json, api/, lib/, dan assets/ pada tingkat yang sama.
02
DEPLOYMENT

Hubungkan GitHub ke Vercel

  1. Buka vercel.com/new lalu login.
  2. Pilih Import Git Repository dan pilih repository nexora-link.
  3. Di pengaturan proyek, gunakan Framework Preset: Other.
  4. Set Root Directory ke root repository (. / kosong / repository root), karena file utama sudah berada di sana.
  5. Biarkan Build Command dan Output Directory kosong/default untuk proyek static + Vercel Functions ini. Jangan arahkan Output Directory ke folder yang tidak ada.
  6. Tambahkan Environment Variables seperti pada langkah 03, lalu tekan Deploy.
03
SERVER SECRETS

Isi Environment Variables Vercel

Buka Vercel → Project → Settings → Environment Variables. Buat variabel berikut. Nilai rahasia dibuat sendiri dan jangan dikirim ke orang lain.

NEXORA_API_KEYKunci akses aplikasi, minimal 32 karakter acak.
BRIDGE_SECRETRahasia enkripsi tiket; minimal 32 karakter. Jangan diganti setelah dipakai.
PUBLIC_BASE_URLURL deploy HTTPS, misalnya https://nama-proyek.vercel.app
APP_REDIRECT_URIOpsional. Default: nexoracloud://link
GOOGLE_CLIENT_IDClient ID dari Google Cloud OAuth Web application.
GOOGLE_CLIENT_SECRETClient Secret Google. Simpan hanya di Vercel.
GOOGLE_DEFAULT_SCOPESOpsional. Disarankan: drive_file,photos_upload,photos_picker
GITHUB_CLIENT_IDClient ID dari GitHub OAuth App.
GITHUB_CLIENT_SECRETClient Secret GitHub. Simpan hanya di Vercel.
TELEGRAM_BOT_TOKENToken bot dari BotFather. Simpan hanya di Vercel.
ALLOWED_TELEGRAM_METHODSOpsional. Daftar metode Bot API dipisah koma.
RATE_LIMIT_PER_MINUTEOpsional. Default 60 permintaan per menit per IP / instance.
TICKET_TTL_DAYSOpsional. Default masa berlaku tiket 180 hari.

Buat secret acak dengan password manager atau perintah openssl rand -base64 48. Setelah mengubah Environment Variables, lakukan Redeploy agar fungsi memakai nilai terbaru.

04
GOOGLE CLOUD

Aktifkan Google Drive & Photos

  1. Buka Google Cloud Console dan pilih/buat project.
  2. Aktifkan Google Drive API, Google Photos Library API, dan Google Photos Picker API yang tersedia untuk project.
  3. Buat OAuth consent screen. Saat status Testing, tambahkan akun Google Anda sebagai Test User.
  4. Buat OAuth Client ID tipe Web application.
  5. Isi Authorized redirect URI dengan alamat https://domain-anda.vercel.app/api/google/callback. Setelah URL deploy diketahui, sesuaikan domainnya.
  6. Masukkan Client ID dan Client Secret ke Environment Variables Vercel, lalu redeploy.
!
Catatan Google Photos: alur Picker mengharuskan pengguna memilih media melalui Google Photos. Jangan menganggap bridge ini menyediakan akses bebas ke seluruh koleksi foto. Perhatikan pembatasan scope dan kebijakan Google yang berlaku.
05
GITHUB OAUTH

Atur GitHub OAuth App

  1. Buka GitHub Developer Settings → OAuth Apps → New OAuth App.
  2. Isi Homepage URL dengan URL Vercel Anda.
  3. Isi Authorization callback URL dengan https://domain-anda.vercel.app/api/github/callback.
  4. Salin Client ID dan buat Client Secret, kemudian masukkan ke Environment Variables Vercel.
  5. Aplikasi Nexora Cloud dapat memakai bridge OAuth atau Personal Access Token secara langsung untuk operasi GitHub tertentu.
06
TELEGRAM BOT API

Hubungkan Telegram Bot

  1. Buka @BotFather di Telegram, buat bot, dan salin token.
  2. Tambahkan token sebagai TELEGRAM_BOT_TOKEN di Vercel. Jangan masukkan token bot ke HTML, GitHub repository, atau APK.
  3. Atur ALLOWED_TELEGRAM_METHODS hanya untuk metode yang memang dibutuhkan. Metode yang tidak diizinkan akan mendapat HTTP 403.
  4. Redeploy lalu jalankan Test API di panel ini.
!
Proxy ini untuk Telegram Bot API, bukan login akun Telegram pribadi melalui TDLib. Jangan kirim nomor telepon, OTP, atau session string TDLib ke endpoint ini.
07
ANDROID PAIRING

Sambungkan ke aplikasi Nexora Cloud

  1. Pastikan deployment Vercel sudah aktif dan https://domain-anda.vercel.app/health mengembalikan JSON dengan "ok": true.
  2. Buka aplikasi Nexora Cloud → Setting → Kustomisasi Penuh → Endpoint API, lalu isi URL Nexora Link dengan URL Vercel Anda.
  3. Buka menu Nexora Link (API Bridge). Isi URL bridge yang sama dan API Key yang persis sama dengan NEXORA_API_KEY di Vercel.
  4. Tekan Simpan, lalu Tes Koneksi. Server harus melaporkan Google, GitHub, dan Telegram sesuai Environment Variables yang tersedia.
  5. Untuk Google, pilih scope yang diperlukan lalu tekan Masuk dengan Google. Setelah login di browser, aplikasi menangani deep link nexoracloud://link dan menyimpan tiket melalui Android SecretStore/Keystore.
  6. Setelah akun Google terhubung, buka menu Google Drive & Photos pada aplikasi untuk memuat layanan cloud. GitHub dan Telegram diatur dari menu integrasinya masing-masing.
ⓘ
Nama menu dapat sedikit berbeda tergantung versi APK. Referensi integrasi yang menyertai proyek Nexora Cloud menyebut pengaturan URL di Kustomisasi Penuh dan URL/API Key di halaman Nexora Link.
08
TROUBLESHOOTING

Atasi error 404: NOT_FOUND

Periksa Root Directory

Jika repository berisi index.html langsung di root, set Root Directory ke root repository. Jangan menunjuk ke folder induk yang hanya berisi folder proyek.

Periksa struktur file

Di root yang dipilih Vercel harus ada index.html, vercel.json, api/, dan lib/. Jangan hanya upload ZIP ke GitHub.

Periksa framework dan output

Gunakan Framework Preset Other. Jangan paksa Output Directory seperti dist jika proyek tidak menghasilkan folder itu.

Periksa deployment terbaru

Buka Vercel → Deployments, pastikan deployment terbaru berstatus Ready. Buka Build Logs bila gagal.

Uji dua alamat

Buka / untuk dashboard dan /health untuk status API. Jika hanya /health yang berhasil, masalah biasanya pada root static file atau Root Directory.

Periksa environment variables

HTTP 503 dengan NOT_CONFIGURED berarti secret server belum lengkap atau deployment belum di-redeploy setelah perubahan env.

Masih ada kendala?

Salin hasil ping dan lihat Vercel Runtime Logs tanpa membagikan API key, client secret, atau token.
